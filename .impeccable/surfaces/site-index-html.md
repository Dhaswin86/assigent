# Start page (site/index.html)

Scope: the public start page of Assigent. Mode: Persuade.
Audience: any student with assignments, with or without Claude Code. Many are wary of AI (cheating, losing their own thinking) and trust clear rules.
Action: copy the one-line install command, then run `assigent run`.
Must keep: the five helpers (Analyst, Source finder, Builder, Evaluator, Tutor), the rules it keeps, what it asks, how to use it, what you need, demo + playground links, MIT and GitHub, "check your school's rules".
Chosen by: the user delegated the choice after research (Gallup Voices of Gen Z 2026, RAND 2025: rising use, falling trust, want clear rules and learning over answers).
